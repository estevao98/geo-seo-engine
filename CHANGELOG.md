# Changelog

## v1.0.0 - Stable Local CLI Baseline

This release marks the first stable public baseline for the local `geo-seo-engine` CLI.

Included:

- Deterministic local CLI workflows for SEO and GEO audits, planning and reporting.
- Project config bootstrap and validation with safe synthetic examples.
- Public URL audits for pages, robots.txt, sitemaps, structured data and site-level reports.
- Bounded crawling, URL inventory, technical checks, rendering checks and local PageSpeed/Lighthouse JSON parsing.
- Content, entity-readiness, internal-link, image, social metadata and hreflang audits.
- Opportunity planning, content briefs, content clusters, AI-readiness simulation and senior reports from local inputs.
- Release, usage, maintenance, security and quality-gate documentation for public repository operation.

Known limits and non-promises:

- Does not promise traffic growth, ranking improvement, indexing, AI citation or inclusion in generative answers.
- Does not create or recommend black hat SEO, PBNs, cloaking, doorway pages, spam or artificial backlinks.
- Does not publish a SaaS/API/dashboard layer in this release.
- Does not publish to PyPI as part of this repository change.
- Uses synthetic examples only; private exports, generated reports and credentials must stay out of the repository.

Release notes:

- Package metadata and `geo version` report `1.0.0`.
- The release is intended to be tagged after review and merge with an annotated `v1.0.0` Git tag.
