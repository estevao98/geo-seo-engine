# Contributing

## Fluxo

1. Criar uma branch pequena.
2. Fazer alterações em chunks.
3. Rodar validações.
4. Revisar diff.
5. Só commitar depois de revisão.

## Antes de finalizar

```bash
git status --short
git diff --stat
git diff --check
```

## Padrões

* Markdown claro.
* JSON/YAML válido.
* Sem segredos.
* Sem dados reais.
* Sem promessas não verificáveis.
