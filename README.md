# geo-seo-engine

Framework operacional para SEO + GEO voltado a SaaS, micro SaaS, blogs, documentação, landing pages e sites institucionais.

## Objetivo

Auditar, planejar, gerar, validar e monitorar estratégias de crescimento orgânico para busca tradicional e mecanismos generativos.

## Escopo inicial

- SEO técnico
- GEO / AI visibility
- Auditoria de conteúdo
- Briefings editoriais
- Quality gates
- Sitemaps
- llms.txt
- Schema markup
- Relatórios
- MCPs customizados planejados

## Estado atual

- MCP stack configurada.
- AGENTS.md criado.
- Scaffold inicial em construção.

## O que este repositório não promete

- Não promete milhões de acessos.
- Não promete indexação garantida.
- Não promete aparecer em respostas de IA.
- Não usa black hat SEO.
- Não cria conteúdo em massa sem validação.
