# Overview — SEO + GEO

## SEO

SEO é o conjunto de práticas para tornar páginas públicas, indexáveis, compreensíveis e úteis para mecanismos de busca.

## GEO

GEO é a adaptação da estratégia de conteúdo e autoridade para mecanismos generativos e experiências de busca com IA.

## Premissa

GEO não substitui SEO técnico. Uma página que não pode ser rastreada, renderizada, entendida ou indexada dificilmente será usada de forma confiável por sistemas de busca com IA.

## Limites

Este projeto não trata GEO como hack de manipulação. O foco é clareza, qualidade, autoridade, evidência, estrutura e mensuração.
