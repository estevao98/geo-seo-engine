# Roadmap de MCPs customizados

## Planejados

* `search_console_mcp`
* `analytics_mcp`
* `lighthouse_mcp`
* `pagespeed_mcp`
* `schema_validator_mcp`
* `ai_visibility_mcp`
* `vector_search_mcp`
* `content_repo_mcp`

## Fase 1

Criar apenas schemas, README e interface das tools.

## Fase 2

Implementar tools locais sem credenciais externas.

## Fase 3

Adicionar integrações reais com OAuth/API keys e logs seguros.

## Fase 4

Adicionar testes, rate limit, auditoria e permissões por tool.
