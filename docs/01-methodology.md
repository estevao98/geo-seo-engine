# Methodology

## Pipeline geral

1. Diagnóstico técnico
2. Diagnóstico semântico
3. Mapeamento de entidades
4. Mapeamento de intenção de busca
5. Planejamento de conteúdo
6. Geração de briefing
7. Revisão editorial
8. Quality gates
9. Publicação
10. Monitoramento

## Critérios

* Indexabilidade
* Clareza de entidade
* Intenção de busca
* Utilidade
* Originalidade
* Evidência
* Links internos
* Schema adequado
* Medição
