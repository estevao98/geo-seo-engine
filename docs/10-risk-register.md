# Risk Register

| Risco                        | Impacto | Mitigação                               |
| ---------------------------- | ------- | --------------------------------------- |
| Conteúdo genérico            | Alto    | Quality gates e revisão editorial       |
| Dados inventados             | Alto    | Claims checker e fontes verificáveis    |
| Segredos no Git              | Alto    | .gitignore, .env.example e revisão      |
| Páginas programáticas fracas | Alto    | Critérios mínimos de conteúdo           |
| Dependência excessiva de IA  | Médio   | Separar geração, revisão e validação    |
| MCPs com permissões amplas   | Alto    | Allowlist e MCPs desativados por padrão |
